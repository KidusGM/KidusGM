# K-Properties - Project Brief

## 1. Problem

Finding properties to rent or buy in Ethiopia can be difficult because property information is often scattered across social media, messaging groups, brokers, signs, and word of mouth.

Customers may have difficulty finding accurate information about:

* Property location
* Price
* Property type
* Number of bedrooms
* Availability
* Photos
* Whether the property is for rent or sale

**K-Properties** aims to provide a centralized platform where customers can browse, search, and view property listings and contact the agency.

The platform will mainly focus on residential properties, including houses, apartments, condominiums, and individual houses within compounds.

## 2. Main Users

### Customer

The main user is a person looking for a property to rent or buy.

The customer can:

* Browse properties
* Search for properties
* Filter properties
* View property details
* Check whether a property is available
* Contact the agency

### Agency / Admin

The agency manages the property listings.

The agency can:

* Add properties
* Edit properties
* Delete properties
* Update property availability
* Manage properties for rent or sale

## 3. What the User Does

A typical customer journey is:

```text
Home
  ↓
Search / Browse Properties
  ↓
Filter Properties
  ↓
Select a Property
  ↓
View Property Details
  ↓
Contact Agency
```

## 4. Main Features

* Property listing
* Search properties
* Filter properties
* Rent/Sale filtering
* Property details
* Property images
* Property availability
* Add property
* Edit property
* Delete property
* Contact agency

## 5. Main Screens

### 1. Home

The user can search for a property and see featured properties.

### 2. Properties

The user can browse all available properties and use search and filters.

### 3. Property Details

The user can view complete information about a selected property.

### 4. Add Property

The agency can add a new property listing.

### 5. Manage Properties

The agency can view, edit, delete, and update the availability of property listings.

### 6. Contact

The user can view agency information and send an inquiry.

## 6. Data Required by Each Screen

| Screen            | Data Needed                                                                                                     |
| ----------------- | --------------------------------------------------------------------------------------------------------------- |
| Home              | Featured properties, property types, locations                                                                  |
| Properties        | Property ID, title, type, location, price, bedrooms, image, availability, listing type                          |
| Property Details  | Property ID, title, images, price, location, type, bedrooms, bathrooms, description, availability, listing type |
| Add Property      | Title, type, location, price, bedrooms, bathrooms, description, images, availability, listing type              |
| Manage Properties | Property ID, title, location, price, type, listing type, availability                                           |
| Contact           | Agency name, phone, email, location, customer inquiry                                                           |

## Property Types

The initial project will support:

* House
* Apartment
* Condominium
* Compound House
* Villa
* Individual rental unit

The platform will support both:

* **For Rent**
* **For Sale**

Vehicle listings may be considered as a future expansion, but they are not part of the initial capstone scope.
